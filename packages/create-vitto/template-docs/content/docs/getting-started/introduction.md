# Introduction

Welcome to Vitto Docs! This documentation site is built with [Vitto](https://github.com/riipandi/vitto), a minimal static site generator powered by Vite and Vento.

## Getting Started

Vitto combines the power of Vite's development experience with Vento's simple templating syntax.

> [!NOTE]
> This documentation template uses markdown-it plugins for enhanced markdown rendering.

### Features

- [x] Markdown-based content
- [x] Built-in search via Pagefind
- [x] Responsive design with Tailwind CSS
- [x] Syntax highlighting for code blocks
