Welcome! This demo shows off the markdown features built into this template. **Everything you see is rendered server-side** — no JavaScript needed for content.

> [!TIP]
> Each markdown file under `content/` becomes a page. Add yours, edit existing ones, or remove what you don't need.

## What's Inside

- [x] GFM alerts (note, tip, warning, caution, important)
- [x] Tabbed content blocks
- [x] Task lists with checkboxes
- [x] Syntax highlighting with Shiki
- [x] Auto-generated table of contents

## Quick Example

A task list to track progress:

- [x] Clone the repository
- [x] Install dependencies
- [ ] Customize the content
- [ ] Deploy to production

> [!CAUTION]
> This is a starter template — not a final product. Replace the content, colors, and branding before going live.
